# 실데이터 스모크 테스트

## 원칙
- 알림 발송 명령(--notify, --now, --scheduler)은 이 스킬에서 절대 실행하지 않는다.
- 호출 수를 최소화한다. 종목은 아래 기본값만 쓰고, 반복 실행은 2회 이내.
- 네트워크 오류·휴장일로 데이터가 비는 것은 코드 결함과 구분해서 보고한다.

## 절차
1. 국내 종목 단일 분석
   ```bash
   python main.py -t 005930
   ```
2. 해외 종목 단일 분석 (Yahoo 폴백 경로 확인)
   ```bash
   python main.py -t AAPL
   ```
   (해외 티커 입력 방식이 다르면 main.py --help 로 확인 후 맞춘다)
3. 스캐너를 수정한 경우에만 실행
   ```bash
   python main.py -l
   ```
4. 각 실행에서 확인할 것
   - 예외(Traceback) 없이 종료되는지
   - AVWAP / OBV 값이 NaN 으로만 채워지지 않았는지
   - 다이버전스 결과가 출력되는지 (없음도 정상일 수 있음)
   - 두 번째 실행이 캐시를 사용하는지 (수집 로그 비교)
