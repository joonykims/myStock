# 세션 인수인계

## 절차
1. 이번 세션에서 한 일을 git log / git diff 와 대화 내용으로 정리한다.
2. docs/PROGRESS.md 를 갱신한다.
   - "최근 완료"에 오늘 끝낸 항목 추가 (10개가 넘으면 오래된 것은 한 줄로 요약)
   - "진행 중"의 상태와 다음 단계 수정
   - "막힌 점"에 해결 못 한 문제와 시도한 내용 기록
3. 이번 세션에서 사용자가 에이전트를 교정한 일이 있으면 docs/LESSONS.md 에 추가한다.
   같은 교훈이 2회 이상 나오면 사용자에게 rules 파일로 승격할지 제안한다.
4. 커밋되지 않은 변경이 있으면 사용자에게 알린다 (임의로 커밋하지 않음).
5. 다음 세션에서 바로 시작할 첫 작업을 한 줄로 제시한다.
