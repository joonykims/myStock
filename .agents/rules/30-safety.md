# 안전 규칙 (예외 없음)

## 실행 전 반드시 사용자 확인
- 파일/디렉터리 삭제 (rm -rf 등)
- git reset --hard, git push --force, 브랜치 삭제
- DB 데이터 변경/삭제 명령, 운영(prod) 프로필 관련 작업
- 의존성 추가, 메이저 버전 업그레이드
- 외부 시스템으로 요청을 보내는 스크립트 실행

## 금지
- 비밀번호, API 키, 토큰을 코드나 문서에 하드코딩하지 않는다. 환경변수나 설정 서버를 사용한다.
- .env, 인증서, 키 파일을 커밋하지 않는다.
- 테스트를 통과시키기 위해 테스트를 삭제하거나 @Disabled 처리하지 않는다. 필요하면 이유를 보고하고 승인받는다.
- 워크스페이스 밖의 파일에 접근하지 않는다.
